# Money Decisions Lab

The psychology behind your money decisions. **Data, not advice.**

English-language educational channel on behavioral finance and career money decisions, built from public data and original charts.

- YouTube: https://www.youtube.com/@MoneyDecisionsLab
- TikTok: https://www.tiktok.com/@moneydecisionslabglobal

## Repositories
- **channel-ops** — how the channel is made: production pipeline, decisions (ADRs), log, data sources, YMYL audit checklist and metrics.

## Principles
1. Every number has a primary source and a retrieval date.
2. Every chart is built from data we publish.
3. Educational only: no investment advice, no product recommendations, no promised returns.
4. Synthetic narration is disclosed; no AI presenter gives advice.
